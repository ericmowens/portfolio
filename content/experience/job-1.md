This was my first internship. My main focus during this internship was to design a new site subdomain with an integrated pdf viewer using React, Node, and Javascript. Octopart aggregates electronic part information, and allowing users to natively view datasheets would simplify the customer experience. It was daunting at first, but I learned that I can really thrive when looking at a pre-existing production codebase. I found it so fascinating to look at the current code and how it worked.

My insight into the code base allowed for a great framework to build a new subdomain. I got to collaborate with the graphics department to discuss and finalize a design format and ensure it was consistent with other pages on the site. I also managed NPM packages for optimal web design and user experience with the new pdf viewer. The site template was deployed using Docker and AWS Lambda for smooth deployment. Finally, I was pleased to hear that this new subdomain measurably increased user retention, leading to additional annual revenue of $15k.
